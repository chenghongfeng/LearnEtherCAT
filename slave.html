从站的两份身份证 ESI（XML）与 SII（EEPROM）

同一台从站在两个地方被描述：设计期的 ESI 文件（XML，人读、配置工具读）和 运行期的 SII（EEPROM 里的字表，主站上电时读）。两者说的必须是同一件事， 否则主站会在启动时用错 PDO 偏移——这是现场最常见的“能通信但数据错位”来源。

2 · SII：EEPROM 里的字表

SII 以 16 位字为单位编址。开头是固定字段（厂商、产品码、修订、序列号、硬件/软件版本、站别名、邮箱配置）， 后面按类别（Category）组织：字符串、通用、FMMU、SyncManager、TxPDO、RxPDO、DC。 主站读 SII 就是为了在还没有 ESI 文件的情况下知道“这台设备怎么配”。 ETG.2010 §1.3–1.4 · ETG.1020 §5

实际地址是“字地址 × 2 = 字节地址”。例如字 0x0000 对应 EEPROM 字节 0x0000–0x0001。 访问通过 ESC 的 0x0F00 EEPROM 接口（读/写/重载）。

自测清单（对应到可视化模块）

  • ESI 能被 Schema 1.21 校验通过，且 ProductCode/Revision 与固件一致。
  • SM0/SM1（邮箱）与 SM2/SM3（过程数据）的长度、方向与 ESI 一致 → ESM 页
  • PDO 映射字节序、位宽、对齐与对象字典一致 → PDO 段
  • AL Status Code 在异常时给出正确码值 → 码表
  • DC 传播延时、偏移、SYNC0 抖动在规格内 → DC 页
  • WKC 行为符合读/写/读写规则 → WKC 段
